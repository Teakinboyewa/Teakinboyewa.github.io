Install QGIS

Download and install the free GIS software used in this course.

Time: about 20 minutesLevel: complete beginner

Watch

“How to Install the Latest QGIS LTR Version on Your Computer (Step-by-Step) 2026” by GISWorld. Watch on YouTube.

More videos:

  • QGIS for Beginners on Mac: Download, Install, Interface Tour & Add Base Maps (GIS Writes)

Before you start

  • QGIS is free and works on Windows, macOS, and Linux.
  • You need about 2–3 GB of free disk space and an internet connection.
  • Installation takes 10–20 minutes. Make sure your laptop is plugged in.

Which version? The download page offers two versions. Choose the Long Term Release (LTR). It is the most stable version, and it is the one this course is written for. The other version ("Latest release") has newer features but changes more often.

Steps on Windows

  1. Go to qgis.org/download.
  2. Download the Long Term Release installer for Windows. It is a large file, so it may take a few minutes.
  3. Open the downloaded file. Click Next, accept the license, keep the default folder, and click Install.
  4. Wait until it finishes, then click Finish.
  5. Open the Start menu and type QGIS. You may see several shortcuts. Open the one called QGIS Desktop followed by the version number.

Steps on a Mac

  1. Go to qgis.org/download and download the Long Term Release for macOS.
  2. Open the downloaded file and drag the QGIS icon into your Applications folder.
  3. Open QGIS from Applications. If macOS says the app "cannot be opened", go to System Settings › Privacy & Security, scroll down, and click Open Anyway.

Check that it worked

When QGIS opens, you see a welcome screen with a list of recent projects (empty the first time). Go to Help › About to see your version number. Write it down; it helps when you ask for help.

Common problems

  • The download is very slow or stops. Try again on a faster connection, or at a different time of day.
  • Not enough disk space. Free up space, or empty your Downloads folder and Recycle Bin.
  • The installer is stuck. Some antivirus programs scan every file, which makes installing slow. Wait a few more minutes before cancelling.
  • The menus in the videos look a bit different. That is normal. Each new version moves things slightly. The steps are the same.
