Organize your files and folders

Simple habits that prevent most beginner problems.

Time: about 10 minutesLevel: complete beginner

Most problems beginners have in GIS are not about GIS at all. They are about files that cannot be found, folders that are messy, or downloads that were never unzipped. Ten minutes of setup now saves hours later.

1. Make one course folder

Create a folder for the course, with one folder for each week inside it:

Documents/RS_course/week01/
Documents/RS_course/week02/
Documents/RS_course/week03/

Inside each week, keep a data folder for downloads and an output folder for results you create.

2. Use simple names

  • Use letters, numbers, and underscores. Write landsat_july.tif, not Landsat image (July) final!!.tif.
  • Avoid spaces, accents, and symbols such as & # ( ) ! in file and folder names. Some GIS tools fail with them, often with confusing error messages.
  • Keep paths short. Avoid burying data ten folders deep.

3. Unzip before you use data

Most GIS data comes as a compressed file (.zip, .tar, or .tar.gz). QGIS cannot always use files inside them directly.

  • Windows: right-click a .zip file and choose Extract All. For .tar files (such as Landsat downloads), install the free program 7-Zip, then right-click and choose 7-Zip › Extract Here.
  • Mac: double-click the file.

4. Keep files that belong together, together

Some data are made of several files with the same name. A shapefile, for example, has .shp, .shx, .dbf, and .prj files. Always move or copy all of them together.

5. Watch out for cloud-synced folders

Folders synced by OneDrive, Google Drive, or Dropbox sometimes lock files while they upload, or keep files "online only". If QGIS cannot open or save a file, try working in a folder that is not synced, and back up your results afterwards.

6. Back up your work

Large raw downloads can always be downloaded again. Your QGIS projects, notes, and results cannot. Copy your output folders to a USB drive or cloud storage at the end of each week.
