GIS fundamentals

How a GIS stores, organizes, and analyzes spatial data, and how to make a proper map in QGIS.

Learning objectives

By the end of this lesson, you will be able to:

  • Explain what a GIS is and how it works together with remote sensing.
  • Compare the vector and raster data models and choose the right one for a task.
  • Read and edit attribute tables.
  • Explain coordinate reference systems, datums, and map projections, and reproject data correctly.
  • Recognize common geospatial file formats.
  • Run core operations in QGIS: selection, buffer, and clip.
  • Design a complete map with a print layout.

Lecture notes

1. What is a GIS?

A geographic information system (GIS) is a system for capturing, storing, analyzing, and displaying data that is tied to locations on the Earth. A GIS has five parts: hardware, software, data, people, and methods.

GIS and remote sensing work hand in hand. Remote sensing produces images of the surface. A GIS combines those images with other data, such as field plots, property boundaries, roads, and rivers, so you can ask questions like "How much forest was lost within 1 km of new roads?" Throughout this course you will use QGIS, a free and open-source GIS.

2. Vector and raster data

A GIS stores the world in one of two ways.

  • Vector data represent features as points (towns, field plots), lines (roads, rivers), or polygons (lakes, forest stands, countries). Each feature has a row of attributes. Vector data are best for features with clear boundaries.
  • Raster data divide space into a grid of equal cells. Each cell holds one value, such as reflectance, elevation, or a land-cover class. The cell size sets the level of detail. Raster data are best for things that vary continuously, and all satellite images are rasters.

3. Attributes

Every vector feature is linked to a row in an attribute table. Each column is a field with a type: integer, decimal, text, or date. You can sort, filter, and calculate fields, and you can join a table to a layer using a shared field, such as a country code.

4. Coordinate reference systems

A coordinate reference system (CRS) tells the GIS where each coordinate is on the Earth. Getting the CRS right is the most important habit in GIS.

  • A datum is a model of the Earth's shape and its position. WGS 84 and NAD83 are common datums.
  • A geographic CRS uses latitude and longitude in degrees. The most common is WGS 84, code EPSG:4326.
  • A projected CRS flattens the Earth onto a plane and uses units such as meters. Every projection distorts area, shape, distance, or direction, so you choose one that keeps the property you need. For example, use an equal-area projection when you measure area.
  • UTM (Universal Transverse Mercator) divides the world into 60 zones, each 6° of longitude wide. Within its zone, UTM keeps distortion small and uses meters. The WGS 84 UTM codes are EPSG:326zz in the Northern Hemisphere and EPSG:327zz in the Southern Hemisphere, where zz is the zone number. To find the zone: zone = floor((longitude + 180) / 6) + 1.
  • EPSG codes are standard numbers that identify each CRS. You can look them up at epsg.io.

Common mistake: QGIS has two very different tools. Set Layer CRS only changes the label that says which CRS the coordinates are in. Use it only when that label is missing or wrong. Reproject Layer actually converts the coordinates into a new CRS. To measure distances or areas in meters, reproject your data to a projected CRS.

QGIS reprojects layers "on the fly", so layers in different CRSs still line up on the map. Calculations, however, use each layer's own CRS. A 1,000-unit buffer on a layer in EPSG:4326 is 1,000 degrees, not 1 km.

5. File formats

  • GeoPackage (.gpkg): a single file that can hold many vector and raster layers. It is the default format in QGIS and the one we recommend.
  • Shapefile (.shp): an older, very common format made of several files with the same name (.shp, .shx, .dbf, and .prj). Always keep them together. Field names are limited to 10 characters.
  • GeoJSON (.geojson): a text format common on the web.
  • GeoTIFF (.tif): the standard format for raster data, including satellite images.
  • CSV: a table that can hold point coordinates in two columns, such as latitude and longitude from a GPS.

6. Core operations

  • Select by attribute: choose features whose values meet a condition, such as "POP_MAX" > 1000000.
  • Select by location: choose features based on where they are relative to another layer, such as towns inside a buffer.
  • Buffer: create a zone at a set distance around features.
  • Clip: cut one layer to the boundary of another.
  • Intersect and dissolve: combine overlapping layers, or merge features that share a value.
  • Field calculator: compute new fields, such as area or length.

7. Making a good map

A finished map needs a clear title, a legend, a scale bar, a north arrow, and a note on the data sources and CRS. Use color with purpose: a categorized style for classes (such as land-cover types) and a graduated style for amounts (such as population). Keep the layout simple, so the reader's eye goes to the main message first.

Key terms

A system for capturing, storing, analyzing, and displaying geographic data.
Vector
A data model that stores features as points, lines, and polygons.
Raster
A data model that stores values in a grid of equal-sized cells.
Attribute table
The table of information linked to the features of a vector layer.
Datum
A model of the Earth's shape and position used as the basis for coordinates.
Coordinate reference system (CRS)
The definition that ties coordinates to locations on the Earth.
Map projection
A method of flattening the curved Earth onto a plane. Every projection causes some distortion.
EPSG code
A standard number that identifies a CRS, such as EPSG:4326 for WGS 84.
Reprojection
Converting coordinates from one CRS to another.
Buffer
A zone drawn at a set distance around features.

Lab 2: Mapping a country's rivers and towns

In this lab, you work with real vector data to practice attribute tables, CRSs, geoprocessing, and map design.

Data: from Natural Earth, download three 1:10m layers: Admin 0 – Countries, Populated Places, and Rivers + lake centerlines. Unzip them into one folder.

Part A. Explore the data

New to this? See the starter guides: Organize your files and folders · Find your way around QGIS
  1. Open the QGIS project you saved in Week 1. Drag the three shapefiles (ne_10m_admin_0_countries, ne_10m_populated_places, ne_10m_rivers_lake_centerlines) from the Browser panel onto the map.
  2. Right-click the countries layer and choose Open Attribute Table. Explore the fields. Find the NAME field.
  3. Open Layer Properties › Information for each layer and note its CRS. All three use a geographic CRS (WGS 84, EPSG:4326).

Part B. Select and export your country

  1. Choose a country. Use Select Features by Expression (the ε icon on the toolbar) with an expression such as "NAME" = 'Nigeria'.
  2. Right-click the layer and choose Export › Save Selected Features As. Choose the GeoPackage format and name the layer country.
  3. Find your country's UTM zone from its central longitude, using the formula in the lecture notes. Note the matching EPSG code. If your country spans several zones, pick the zone at its center.

Part C. Reproject and compare areas

  1. Open the field calculator on country and create a decimal field area_deg with the expression area($geometry). This gives the area in the layer's own units, which here are square degrees.
  2. Run Vector › Data Management Tools › Reproject Layer on country, with your UTM CRS as the target. Save the result as country_utm in your GeoPackage.
  3. On country_utm, create a field area_km2 with area($geometry) / 1000000. Compare it with the official area of your country. Why is area_deg not useful for measuring area?

Part D. Clip, buffer, and select

  1. Reproject the rivers and populated places layers to the same UTM CRS.
  2. Run Vector › Geoprocessing Tools › Clip to cut the rivers to country_utm. Do the same for populated places.
  3. Run Vector › Geoprocessing Tools › Buffer on the clipped rivers with a distance of 10,000 m (10 km). Turn on Dissolve result.
  4. Use Vector › Research Tools › Select by Location to select the towns that intersect the river buffer. How many of the country's towns are within 10 km of a major river?

Part E. Style and lay out the map

  1. Style the towns with a graduated symbol based on POP_MAX, so bigger cities get bigger circles. Style the rivers in blue and the buffer in a light, semi-transparent color.
  2. Add labels for the largest cities under Layer Properties › Labels.
  3. Open Project › New Print Layout. Add the map, a title, a legend, a scale bar, a north arrow, and a text box with the data source (Natural Earth) and the CRS.
  4. Export the map with Layout › Export as PDF.

What to submit

  • Your finished map as a PDF.
  • Your country's area in square degrees and in km², the official area, and two to three sentences explaining the difference.
  • The number of towns within 10 km of a major river, and the UTM EPSG code you used.

Check your understanding

1. Would you store a road network as vector or raster? What about a land-cover map made from satellite imagery?

Roads are discrete lines with clear positions, so vector is the natural choice. A land-cover map made from an image covers every pixel with a class, so it is usually a raster.

2. What is the difference between "Set Layer CRS" and "Reproject Layer"?

Set Layer CRS only changes the label that says which CRS the coordinates are in; the coordinates themselves do not change. Reproject Layer converts the coordinates into a new CRS, creating a new layer.

3. What is EPSG:4326, and why is it a poor choice for measuring distances?

EPSG:4326 is the geographic CRS WGS 84, with coordinates in degrees of latitude and longitude. The ground length of a degree of longitude shrinks toward the poles, so distances and areas in degrees do not match real-world meters.

4. State College, Pennsylvania, is at about 77.86° W. What UTM zone and EPSG code would you use?

zone = floor((−77.86 + 180) / 6) + 1 = floor(17.02) + 1 = 18. It is in the Northern Hemisphere, so the code is EPSG:32618 (WGS 84 / UTM zone 18N).

5. Which files must you keep together when you share a shapefile?

At least the .shp (geometry), .shx (index), and .dbf (attributes). Also keep the .prj file, which stores the CRS. Without it, QGIS does not know where the data belong.

6. Name five elements a finished map should have.

A title, a legend, a scale bar, a north arrow, and a note on data sources and CRS.
