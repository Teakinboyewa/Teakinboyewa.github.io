Install a plugin

Add extra tools to QGIS from the free plugin library.

Time: about 10 minutesLevel: complete beginner

Watch

“How to Find and Install Plugins in QGIS (Latest Version of QGIS)” by Satellite Remote Sensing and GIS. Watch on YouTube.

Plugins are free add-ons that give QGIS new tools. There are hundreds of them, written by people around the world.

Steps

  1. Go to Plugins › Manage and Install Plugins.
  2. Click the All tab and type the plugin's name in the search box, for example QuickMapServices.
  3. Click the plugin, read its description, and click Install Plugin.
  4. Close the window. The new tool appears in a menu (often Plugins, Web, Raster, or Vector) or as a new toolbar button.

Managing plugins

  • The Installed tab lists your plugins. Untick a plugin to turn it off, or click Uninstall Plugin to remove it.
  • The Upgradeable tab shows plugins with updates.
  • If a plugin causes errors, turn it off first. It is the quickest fix.

Plugins worth knowing

  • QuickMapServices: adds many basemaps.
  • Value Tool: shows the pixel values of all raster layers under your mouse.
  • SpatialAnalysisAgent: an AI assistant that runs spatial analysis in QGIS from plain-language requests.
